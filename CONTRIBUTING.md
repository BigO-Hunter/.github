# Contributing

BigO-Hunter formalizes improved algorithmic and mathematical bounds in Lean 4 and files
them toward the [BigO Speedrun](https://github.com/bigospeedrun) initiative. The
[org manifest](profile/README.md) maps every repo by row; each repo's README states its
result, evidence and next steps. Start there to find the right repo.

## How to contribute

- **Proofs, certificates, audits** — open a pull request in the relevant repo. Constructions
  are credited to their original authors; filings cite provenance.
- **Questions and findings** — open an issue in the relevant repo. An ambiguity a question
  exposes is exactly the kind of finding worth collecting.
- **Methodology** — see [`bigospeedrun-agent-kit`](https://github.com/BigO-Hunter/bigospeedrun-agent-kit).
  Contributions flow upstream to [`bigospeedrun`](https://github.com/bigospeedrun) as PRs.

Work is AI-assisted and disclosed (darkhipo swarm). Write to be read by humans: plain words,
short sentences.
