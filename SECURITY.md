# Security

This repo holds the org's community documentation and the [CFSF license](LICENSE) text.

To report a security issue, open a **private security advisory** on the relevant repo, or
email **dima@darkhipo.info**. For a defect in the license *wording* — an ambiguity that could
be exploited against adopters — a private advisory or an issue is the right path. Wording
defects are treated with the seriousness of security defects; that is the point of a
canonical home.
